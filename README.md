# Арзамас 90-е

Top-down криминальная игра про Арзамас 1991–1999 годов. Один файл `index.html`: чистый JavaScript и Canvas, без библиотек, сборки и внешних ресурсов. Прогресс, настройки управления и язык сохраняются в `localStorage`.

## Состав проекта

| Файл | Назначение |
| --- | --- |
| `index.html` | Вся игра: код, процедурная графика, звук. Это же страница для GitHub Pages. |
| `regression-tests.html` | 40 автоматических проверок (физика, интерьеры, интерфейс, автомобили). Нужен локальный сервер. |
| `.nojekyll` | Пустой файл-страховка для GitHub Pages: отключает обработку Jekyll. Для этого проекта не обязателен (нет файлов и папок, начинающихся с `_`), но не мешает. |
| `.gitignore` | Исключает архив старой сборки и файлы macOS. |

## Запуск на компьютере

- Откройте `index.html` двойным кликом (Chrome, Safari, Firefox).
- Либо локальный сервер: `python3 -m http.server 8000`, затем http://localhost:8000
- Страница тестов работает только через сервер: при открытии по `file://` браузер блокирует чтение `index.html`. Откройте http://localhost:8000/regression-tests.html и нажмите «Запустить проверки».

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на github.com, например `arzamas-90s`.
2. Загрузите файлы `index.html`, `regression-tests.html`, `README.md`, `.nojekyll` (Add file → Upload files). Либо из папки проекта:

```bash
git init
git add .
git commit -m "Арзамас 90-е"
git branch -M main
git remote add origin https://github.com/<ваш-ник>/arzamas-90s.git
git push -u origin main
```

3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты игра откроется по адресу `https://<ваш-ник>.github.io/arzamas-90s/`, в том числе на телефоне. На iPhone: Поделиться → На экран «Домой».

Важно: имя файла должно быть именно `index.html`, иначе GitHub Pages отдаст 404. Скрытый файл `.nojekyll` можно не загружать: без него сайт тоже работает.

## Управление

**Компьютер:** WASD или стрелки — движение; мышь — прицел и огонь (либо J); Shift — бег; Ctrl — тихий шаг; Пробел — рывок; F — бита; Q или 1–3 — смена оружия; E — «Действие» (вход и выход, посадка в машину, покупка, ограбление); R — ручной тормоз; M — карта города; Esc — пауза.

Все клавиши переназначаются: главное меню → «НАСТРОЙКИ» → «Управление». Нажмите кнопку с действием и введите новую клавишу. Назначения сохраняются в браузере; «Сброс управления» возвращает стандартные.

**Телефон:** джойстик слева, кнопки ОГОНЬ, БИТА, ОРУЖ, РЫВОК, ДЕЙСТВИЕ. В машине: джойстик — руль, справа ГАЗ и ТОРМОЗ (тормоз на скорости с выкрученным рулём даёт занос).

## Что реализовано

- **Физика.** Персонаж быстро отзывается на управление и лишь слегка тормозит по инерции, есть бег, тихий шаг и рывок. Пули рикошетят под углом с потерей скорости, прямое попадание в тонкое препятствие гасится. Предметы отскакивают по импульсу. Ни герой, ни машина, ни предметы не проходят сквозь стены: движение разбивается на подшаги с проверкой коллизий.
- **Автомобили.** У каждой марки своя масса (от 945 кг у ВАЗ-2109 до 7080 кг у КамАЗа), максимальная скорость и сцепление. Простые машины по марке (ВАЗ-2106, 2107) медленнее и хуже держат дорогу — сильнее сносит в повороте; Волга, BMW, Mercedes и Porsche едут быстрее и устойчивее. Наезд на героя сбивает его с ног и наносит урон тем больший, чем выше скорость.
- **Поломки машин.** При первом выезде на конкретной машине есть шанс поломки (чаще у простых отечественных марок, реже у премиума). Двигатель либо «троит» — тянет еле-еле с рывками, либо глохнет — машина тормозит до полной остановки. При очень долгой непрерывной езде двигатель тоже изнашивается. О поломке сообщается надписью после начала движения.
- **Интерьеры и безопасные зоны.** Кабак «Ракушка», гаражный кооператив, продуктовый, рынок, оружейный и ресторан гостиницы «Арзамас» — отдельные внутренние локации. Внутри урон, выстрелы, ограбления и агрессия отключены. Механики: на рынке и в магазинах — покупки; в гараже — ремонт и сохранение машины, оставленной у ворот; в кабаке — платный инсайд по текущему делу.
- **Карта города.** Реальные ориентиры по схеме: ул. Калинина, Коммунистов, 9 Мая, Володарского, Чехова, пр. Ленина, Революции, трасса Р-72; парк Гайдара, Соборная площадь, Колхозный рынок, автостанция, АПЗ, музей Гайдара, река Тёша. В меню есть интерактивная карта с плавным зумом (кнопки «+» и «−», колесо, щипок), перетаскиванием и кнопкой «К ГЕРОЮ». Названия улиц выводятся только на этой карте.
- **Оговорка по точности.** Карта — читаемая схема города, а не геодезическая копия. В коде это помечено флагами `GEO.verified=false` и `verified:false` у дверей: сверка по OpenStreetMap не выполнялась, поскольку сервисы геоданных были недоступны. `geoToWorld(lat, lon)` переводит реальные координаты (WGS-84) в игровые и готов к загрузке проверенных данных.
- **Прочее.** 8 глав сюжета (1991–1999) с катсценами, финал и секретная концовка «Свобода»; смена дня и ночи; прохожие, которых можно ограбить; русский и английский язык; синтезированная музыка, зависящая от района.

## Автомобили в игре

ВАЗ-2106, ВАЗ-2107, ВАЗ-2109, ГАЗ-3110 «Волга», ПАЗ-672, Mercedes W124, BMW E34, Porsche 911, ГАЗ-53, КамАЗ-5320. В трафике встречаются автобусы и грузовики; в автобус можно сесть пассажиром или угнать.

## Своя музыка

По умолчанию играет синтезированная музыка. Свои треки (только с правом на использование, например CC0): в `index.html` найдите `const TRACKS={rock:"",pop:"",chanson:""}` и вставьте ссылки на mp3.

## Свои спрайты

Найдите `const ASSETS={player:null,enemy:null}` и подставьте `Image` 16×16 (взгляд вправо).
